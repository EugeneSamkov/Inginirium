# Фруктовый лабиринт

Версия игры на Python и PyGame. В игре лабиринт с параметрами расширенного уровня. Ёжик ищет выход из лабиринта, собирает необязательные фрукты и избегает ловушек. Очки и общий топ-5 сохраняются с помощью SQLite3.

## Установка и запуск

Нужны Python 3.10+ и графический рабочий стол.

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python game.py
```

Введите никнейм и нажмите Enter. Прочитайте правила и нажмите Enter для начала игры. Управляйте стрелками. Нужно добраться до зелёного выхода за 60 секунд; фрукты приносят по одному очку, но для победы не обязательны. Жёлтые ловушки останавливают игрока на 5 секунд, пока таймер продолжает идти. Если время закончилось, игрок проигрывает. На итоговом экране показываются пять лучших игроков по их максимальному числу очков. Enter запускает новую партию, Esc возвращает к вводу имени; во время игры Esc закрывает программу.

`ScoreDatabase` создаёт базу `scores.sqlite3` рядом с `game.py`, сохраняет каждую завершённую партию и запрашивает топ-5. База создаётся автоматически и не включена в Git. `Player` отвечает за движение главного персонажа, `Maze` генерирует проходимый лабиринт, `Game` управляет экранами и правилами.
